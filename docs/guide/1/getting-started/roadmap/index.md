# Roadmap

## v1.0.0 - The Core

- [x] Add Symfony web application skeleton.
- [x] Add artwork, favicon, logo, and social-preview card.
- [x] Add default GitHub workflows and issue templates.
- [x] Add documentation and instruction files.
